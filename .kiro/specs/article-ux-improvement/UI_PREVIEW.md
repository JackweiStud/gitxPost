## ✨ 核心改进点

### 1. 紧凑头部（60px）
**位置**：页面顶部
**内容**：
- `← 返回` 按钮
- 标题输入框（可编辑，失焦自动保存）
- 风格选择器下拉菜单：`[Zara 风格 ▼]` `[技术风格 ▼]` `[趣味风格 ▼]`
- 步骤徽章：`骨架` `内容` `预览`（不同颜色）
- 状态徽章：`草稿` `生成中` `已发布`（不同颜色）

### 2. 进度指示器
**位置**：编辑区域上方
**显示时机**：点击"一键生成"后出现
**内容**：
- 当前步骤标题：`生成骨架` 或 `生成全文`
- 进度百分比：`45%`
- 进度条：蓝色渐变，带动画效果
- 状态消息：
  - 骨架阶段：`正在分析主题...` → `正在生成大纲...` → `正在优化结构...`
  - 全文阶段：`正在扩展第 1/5 章节...` → `正在扩展第 2/5 章节...`
- `[取消]` 按钮

### 3. 编辑器增强
**位置**：左侧面板
**新功能**：
- **工具栏**：`[📷 插入图片]` 按钮
- **自动保存**：编辑后 3 秒自动保存
- **图片插入**：
  - 点击工具栏按钮选择图片
  - 拖拽图片到编辑器
  - 粘贴图片（Cmd/Ctrl+V）
  - 上传时显示：`上传中... 67%`
  - 自动插入：`![image](/images/articles/art_123/image_456.png)`

### 4. 浮动操作面板
**位置**：右下角固定
**内容**：
- **保存状态**：
  - `✓ 已保存 14:30`（绿色）
  - `⟳ 保存中...`（蓝色，旋转动画）
  - `• 未保存`（黄色）
  - `⚠ 保存失败`（红色）
- **主按钮**（根据步骤动态切换）：
  - 标题/骨架步骤：`[一键生成]`（蓝色大按钮）
  - 内容步骤：`[发布文章]`（绿色大按钮）
- **预览按钮**：`[👁]`（图标按钮）

## 🎬 用户操作流程

### 场景 1：一键生成文章

```
1. 用户打开文章编辑页
   ↓
2. 输入标题："AI 技术趋势分析"
   ↓
3. 选择风格：点击下拉菜单 → 选择"技术风格"
   ↓
4. 点击右下角"一键生成"按钮
   ↓
5. 进度指示器出现：
   - "生成骨架 0%"
   - "正在分析主题..."
   ↓
6. 进度增长：
   - "生成骨架 30%"
   - "正在生成大纲..."
   ↓
7. 骨架完成，自动进入全文生成：
   - "生成全文 50%"
   - "正在扩展第 1/5 章节..."
   ↓
8. 全文完成：
   - "生成全文 100%"
   - 进度指示器消失
   - 内容自动填充到编辑器
   ↓
9. 用户可以编辑内容
   - 3 秒后自动保存
   - 浮动面板显示"✓ 已保存 14:30"
```

### 场景 2：插入图片

```
方式 1：点击工具栏
1. 点击"插入图片"按钮
2. 选择图片文件
3. 显示"上传中... 67%"
4. 自动插入 Markdown 语法

方式 2：拖拽
1. 从文件管理器拖拽图片
2. 放到编辑器上
3. 自动上传并插入

方式 3：粘贴
1. 复制图片（截图）
2. 在编辑器按 Cmd/Ctrl+V
3. 自动上传并插入
```

### 场景 3：键盘快捷键

```
Cmd/Ctrl + S       → 手动保存（阻止浏览器默认行为）
Cmd/Ctrl + Enter  → 一键生成（标题/骨架步骤）或发布（内容步骤）
Cmd/Ctrl + P      → 预览切换（待实现）
```

## 🎨 颜色方案

### 步骤徽章
- **标题**：蓝色 `#1e40af` / 背景 `#eff6ff`
- **骨架**：黄色 `#92400e` / 背景 `#fef3c7`
- **内容**：绿色 `#065f46` / 背景 `#d1fae5`
- **预览**：紫色 `#3730a3` / 背景 `#e0e7ff`

### 状态徽章
- **草稿**：灰色 `#6b7280` / 背景 `#f3f4f6`
- **生成中**：蓝色（带动画）
- **已发布**：绿色 `#065f46` / 背景 `#d1fae5`

### 保存状态
- **已保存**：绿色 `#10b981` ✓
- **保存中**：蓝色 `#3b82f6` ⟳（旋转）
- **未保存**：黄色 `#f59e0b` •
- **保存失败**：红色 `#ef4444` ⚠

### 按钮
- **一键生成**：蓝色 `#3b82f6` → hover `#2563eb`
- **发布文章**：绿色 `#10b981` → hover `#059669`
- **取消**：灰色边框，hover 变深

## 📐 尺寸规格

- **头部高度**：60px（旧版 ~120px）
- **进度指示器高度**：~120px
- **浮动面板宽度**：200px
- **编辑器/预览**：50/50 分屏
- **工具栏高度**：40px

## 🔄 动画效果

1. **进度条**：平滑增长动画（0.3s ease-out）
2. **进度条光泽**：从左到右滑动动画（2s 循环）
3. **保存中图标**：旋转动画（1s 循环）
4. **按钮 hover**：向上移动 1px + 阴影
5. **进度指示器**：淡入淡出（0.3s）

## 🚀 与旧版本对比

| 功能 | 旧版本 | 新版本 |
|------|--------|--------|
| 生成方式 | 手动点击"生成骨架" → 等待 → 手动点击"生成全文" | 一键生成，自动完成 |
| 风格选择 | 写死在代码中 | UI 下拉菜单选择 |
| 进度反馈 | 只有小的状态消息 | 详细进度条 + 百分比 + 状态消息 |
| 保存方式 | 手动点击保存按钮 | 3 秒自动保存 |
| 图片插入 | 不支持 | 拖拽/点击/粘贴三种方式 |
| 键盘快捷键 | 不支持 | Cmd+S, Cmd+Enter, Cmd+P |
| 头部高度 | ~120px | 60px（节省空间） |
| 操作按钮 | 分散在各处 | 集中在右下角浮动面板 |
