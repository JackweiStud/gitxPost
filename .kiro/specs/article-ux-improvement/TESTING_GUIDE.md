# 文章工作站 UX 改进 - 测试指南

## 前置条件

1. 启动后端服务器：
```bash
cd web/api
python server.py
# 或
uvicorn server:app --reload --port 8900
```

2. 启动前端开发服务器：
```bash
cd web/ui
npm run dev
# 或
yarn dev
```

3. 确保浏览器可以访问：
   - 后端：http://127.0.0.1:8900
   - 前端：http://localhost:5173（或其他端口）

## 测试场景

### 优先级 1: 文章发布主链路

1. 访问文章列表页：`/articles`
2. 点击"创建新文章"按钮
3. 输入文章标题（例如："测试文章 - AI 技术趋势"）
4. 在头部选择文章风格：
   - Zara 风格（默认）
   - 技术风格
   - 趣味风格
5. 点击右下角浮动面板的"一键生成"按钮
6. 观察：
   - ✅ 进度指示器以日志流方式出现
   - ✅ 日志会逐条追加，能看出后台正在做什么
   - ✅ 状态消息显示当前步骤
   - ✅ 可以点击"取消"按钮中断生成
   - ✅ 生成完成后内容自动填充到编辑器
   - ✅ 若正文包含图片占位符，系统会自动生成并插入配图，预览同步显示
7. 继续编辑生成后的内容，确认能正常保存并进入发布流程
8. 点击"发布文章"，确认最终状态变为已发布

### 优先级 2: 图片插入与预览

#### 方式 1: 点击工具栏按钮
1. 点击编辑器工具栏的"插入图片"按钮
2. 选择一张图片文件（PNG/JPG/GIF/WebP）
3. 观察：
   - ✅ 显示"上传中... X%"
   - ✅ 上传完成后自动插入 Markdown 语法
   - ✅ 右侧预览显示图片

#### 方式 2: 拖拽图片
1. 从文件管理器拖拽图片到编辑器
2. 观察：
   - ✅ 图片自动上传并插入
   - ✅ 右侧预览显示图片

#### 方式 3: 粘贴图片
1. 复制一张图片（截图或从其他应用复制）
2. 在编辑器中按 Cmd/Ctrl+V
3. 观察：
   - ✅ 图片自动上传并插入
   - ✅ 右侧预览显示图片

### 优先级 3: 自动保存

1. 在编辑器中修改内容
2. 停止输入 3 秒
3. 观察：
   - ✅ 浮动面板显示"保存中..."
   - ✅ 3 秒后显示"已保存 HH:MM"
   - ✅ 保存状态图标变为绿色 ✓

### 优先级 4: 紧凑头部与风格保存

1. 观察头部高度：
   - ✅ 约 60px（比旧版本更紧凑）

2. 编辑标题：
   - 点击标题输入框
   - 修改标题
   - 点击其他地方（失焦）
   - ✅ 标题自动保存

3. 切换风格：
   - 点击风格选择器下拉菜单
   - 选择不同风格
   - ✅ 风格保存到文章元数据
   - ✅ 下次创建文章时记住上次选择

4. 步骤徽章：
   - ✅ 显示当前步骤（标题/骨架/内容/预览）
   - ✅ 不同步骤有不同颜色

5. 状态徽章：
   - ✅ 显示文章状态（草稿/生成中/已发布）

### 优先级 5: 浮动操作面板

1. 观察面板位置：
   - ✅ 固定在右下角
   - ✅ 始终可见（不随页面滚动）

2. 保存状态指示：
   - ✅ 显示当前保存状态
   - ✅ 显示最后保存时间

3. 按钮显示逻辑：
   - 标题/骨架步骤：显示"一键生成"按钮
   - 内容步骤：显示"发布文章"按钮
   - ✅ 按钮根据步骤动态切换

4. 预览切换按钮：
   - ✅ 显示眼睛图标

### 优先级 6: 键盘快捷键

1. **Cmd/Ctrl+S**: 手动保存
   - 按下快捷键
   - ✅ 浏览器不弹出保存对话框（已阻止默认行为）
   - ✅ 内容自动保存

### 优先级 7: 进度指示器

1. 触发一键生成
2. 观察进度指示器：
   - ✅ 只显示文字日志，不显示阶段卡片、进度条或百分比
   - ✅ 文案按真实流程逐步追加，例如“已提交一键生成...”“后端开始整理文章骨架...”“正文已生成并同步回编辑器”
   - ✅ 看起来像控制台日志，而不是进度面板
   - ✅ 显示"取消"按钮

3. 点击取消按钮：
   - ✅ 生成任务中断
   - ✅ 进度指示器消失
   - ✅ 保留已生成的部分内容
   - ✅ 日志内容停止更新，页面恢复可编辑
4. 生成完成后：
   - ✅ 编辑器内容自动刷新
   - ✅ 不需要手动按 F5

## 常见问题排查

### 问题 1: 点击"一键生成"没有反应

**可能原因**：
1. 后端服务未启动
2. WebSocket 连接失败
3. 文章 ID 不正确

**排查步骤**：
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签页是否有错误
3. 查看 Network 标签页：
   - 检查 `/api/articles/{id}/auto-generate` 请求是否成功
   - 检查 WebSocket 连接状态（ws://127.0.0.1:8900/ws/articles）
4. 确认后端服务正在运行：`curl http://127.0.0.1:8900/api/status`

### 问题 2: 图片上传失败

**可能原因**：
1. 图片格式不支持
2. 图片大小超过 10MB
3. 文章目录不存在

**排查步骤**：
1. 检查图片格式（仅支持 PNG/JPG/GIF/WebP）
2. 检查图片大小（最大 10MB）
3. 查看浏览器 Console 是否有错误信息
4. 检查后端日志

### 问题 3: 自动保存不工作

**可能原因**：
1. 文章 ID 未传递给编辑器
2. 网络请求失败

**排查步骤**：
1. 检查 MarkdownEditor 组件是否接收到 `article-id` prop
2. 查看 Network 标签页的 PUT 请求
3. 确认 3 秒延迟后才会触发保存

### 问题 4: 键盘快捷键不工作

**可能原因**：
1. 焦点不在页面上
2. 输入法拦截了快捷键
3. 浏览器扩展拦截了快捷键

**排查步骤**：
1. 确保点击了页面（焦点在页面上）
2. 切换到英文输入法
3. 尝试在无痕模式下测试（禁用扩展）

### 问题 5: 组件样式错乱

**可能原因**：
1. CSS 变量未定义
2. 浏览器缓存问题

**排查步骤**：
1. 硬刷新页面（Cmd/Ctrl+Shift+R）
2. 清除浏览器缓存
3. 检查是否有 CSS 加载错误

## 性能检查

### 页面加载时间
- ✅ 目标：< 1 秒
- 测试：打开开发者工具 → Performance 标签 → 录制页面加载

### 自动保存响应时间
- ✅ 目标：< 500ms
- 测试：查看 Network 标签页中 PUT 请求的响应时间

### WebSocket 延迟
- ✅ 目标：< 100ms
- 测试：查看 WebSocket 消息的时间戳差异
