# Web UI 文章功能手动测试计划

## 测试环境

- **后端**: http://127.0.0.1:8900
- **前端**: http://localhost:5173
- **浏览器**: Chrome/Firefox/Safari

## 测试前准备

1. 启动后端服务: `cd web/api && ../../.venv/bin/python server.py`
2. 启动前端服务: `cd web/ui && npm run dev`
3. 打开浏览器开发者工具（F12）查看控制台和网络请求

## 测试用例

### 1. 文章列表页面测试

#### 1.1 访问文章列表页
- [ ] 访问 http://localhost:5173/articles
- [ ] 验证页面标题显示"📝 文章管理"
- [ ] 验证"新建文章"按钮可见

#### 1.2 空列表状态
- [ ] 如果没有文章，验证显示空状态提示
- [ ] 验证空状态图标和文字显示正确
- [ ] 验证"创建第一篇文章"按钮可见

#### 1.3 文章列表显示
- [ ] 如果有文章，验证文章卡片正确显示
- [ ] 验证每个卡片显示：标题、状态、更新时间、步骤
- [ ] 验证状态徽章颜色正确（草稿=黄色，已发布=绿色）
- [ ] 验证时间格式化正确（刚刚/X分钟前/X小时前/X天前）

#### 1.4 创建文章
- [ ] 点击"新建文章"按钮
- [ ] 验证弹出输入框
- [ ] 输入标题"测试文章 - 手动测试"
- [ ] 验证创建成功并跳转到编辑器页面
- [ ] 验证控制台无错误

#### 1.5 删除文章
- [ ] 点击文章卡片的删除按钮
- [ ] 验证弹出确认对话框
- [ ] 点击"取消"，验证对话框关闭且文章未删除
- [ ] 再次点击删除按钮
- [ ] 点击"删除"，验证文章被删除
- [ ] 验证文章从列表中消失

### 2. 文章编辑器页面测试

#### 2.1 页面加载
- [ ] 从列表点击文章卡片进入编辑器
- [ ] 验证页面标题显示文章标题
- [ ] 验证状态徽章显示正确
- [ ] 验证工作流步骤显示（4个步骤）
- [ ] 验证当前步骤高亮显示

#### 2.2 编辑器和预览
- [ ] 验证左侧编辑器可见
- [ ] 验证右侧预览可见
- [ ] 在编辑器输入 Markdown 内容
- [ ] 验证预览实时更新
- [ ] 验证 Markdown 渲染正确（标题、列表、代码块等）

#### 2.3 保存草稿
- [ ] 修改内容
- [ ] 点击"保存草稿"按钮
- [ ] 验证显示"保存中..."
- [ ] 验证保存成功提示
- [ ] 刷新页面，验证内容已保存

#### 2.4 生成骨架（Step 1: title → outline）
- [ ] 创建新文章（step=title）
- [ ] 验证显示"生成骨架"按钮
- [ ] 点击"生成骨架"按钮
- [ ] 验证按钮变为"生成中..."
- [ ] 验证状态消息显示"正在生成骨架..."
- [ ] 等待 WebSocket 事件
- [ ] 验证生成成功后：
  - 编辑器内容更新为骨架
  - 步骤变为"骨架"（高亮第2步）
  - 按钮变为"生成全文"
  - 显示成功提示

#### 2.5 生成全文（Step 2: outline → content）
- [ ] 在骨架步骤，验证显示"生成全文"按钮
- [ ] 点击"生成全文"按钮
- [ ] 验证按钮变为"生成中..."
- [ ] 验证状态消息显示"正在生成全文..."
- [ ] 等待 WebSocket 事件
- [ ] 验证生成成功后：
  - 编辑器内容更新为完整文章
  - 步骤变为"内容"（高亮第3步）
  - 按钮变为"发布文章"
  - 显示成功提示

#### 2.6 发布文章（Step 3: content → published）
- [ ] 在内容步骤，验证显示"发布文章"按钮
- [ ] 点击"发布文章"按钮
- [ ] 验证弹出确认对话框
- [ ] 点击"确定"
- [ ] 验证按钮变为"发布中..."
- [ ] 验证状态消息显示"正在发布文章..."
- [ ] 等待 WebSocket 事件
- [ ] 验证发布成功后：
  - 状态徽章变为"已发布"（绿色）
  - 显示成功提示
  - 按钮消失或禁用

#### 2.7 WebSocket 连接
- [ ] 打开浏览器开发者工具 → Network → WS
- [ ] 验证 WebSocket 连接建立（ws://127.0.0.1:8900/ws/articles）
- [ ] 验证连接状态为"已连接"
- [ ] 触发生成操作，验证收到 WebSocket 消息
- [ ] 离开页面，验证 WebSocket 连接断开

#### 2.8 返回按钮
- [ ] 点击左上角"返回"按钮
- [ ] 验证返回到文章列表页面
- [ ] 验证 WebSocket 连接已断开
